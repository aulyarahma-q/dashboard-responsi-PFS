# Dashboard Responsi (React-Bootstrap)

Proyek Dashboard berbasis **React.js** dan **React-Bootstrap** yang dirancang untuk memenuhi kebutuhan antarmuka responsif, modern, dan interaktif.

## 🚀 Fitur Utama
* **Responsive Layout:** Tampilan optimal di berbagai ukuran layar (Desktop, Tablet, Mobile) berkat sistem grid Bootstrap.
* **Component-Based:** Dibangun menggunakan komponen modular React dan styling dari React-Bootstrap.
* **Modern UI Elements:** Menggunakan card, tabel, navigasi, dan elemen UI interaktif lainnya.

## 🛠️ Teknologi yang Digunakan
* [React.js](https://reactjs.org/) - JavaScript Library
* [React-Bootstrap](https://react-bootstrap.github.io/) - UI Framework berbasis Bootstrap
* [HTML5 & CSS3 / SCSS](https://developer.mozilla.org/)
